# Paste Image 插件推荐

## 为什么推荐 Paste Image？

写 Markdown 时，插入图片通常要先保存截图，再找文件位置，最后手动写路径。Paste Image 把这几步合在了一起：按下 `Ctrl + Alt + V`，插件会保存截图，并把图片链接插入 Markdown。

---

## 主要功能

* 直接粘贴截图到 Markdown

* 自动命名图片文件，可自定义前缀

* 自动保存到指定目录

* 插入相对路径的 Markdown 图片链接

* 支持 Windows、macOS 和 Linux

---

## 安装方法

### 方式 1：直接安装

>[跳转安装](https://marketplace.visualstudio.com/items?itemName=mushan.vscode-paste-image)

### 方式 2：在 VS Code 插件市场安装

1. 打开 VS Code
2. 按 `Ctrl + Shift + X` 打开扩展市场
3. 搜索 `Paste Image`
4. 点击“安装”

### 方式 3：手动安装

也可以在 VS Code 命令面板（`Ctrl + Shift + P`）里运行：

```sh
ext install mushan.vscode-paste-image
```

---

## 推荐配置（`settings.json`）

可以在 VS Code 的 `settings.json` 里加入以下配置：

```json
{
  "pasteImage.namePrefix": "${currentFileNameWithoutExt}_",
  "pasteImage.path": "${projectRoot}/public/posts",
  "pasteImage.basePath": "${projectRoot}/public",
  "pasteImage.forceUnixStyleSeparator": true,
  "pasteImage.prefix": "../"
}
```

配置说明：
| 配置项 | 说明 | 示例 |
|--------|------|------|
| `"pasteImage.namePrefix"` | 图片名称的前缀，`${currentFileNameWithoutExt}_` 表示当前文件名作为前缀 | `index_20250130.png` |
| `"pasteImage.path"` | 图片存放路径，相对于 `projectRoot` | `source/photo/` |
| `"pasteImage.basePath"` | `basePath` 影响 Markdown 里图片的路径 | `source/` |
| `"pasteImage.forceUnixStyleSeparator"` | 是否强制使用 `/` 作为路径分隔符，避免 Windows 反斜杠 `\` 问题 | `true` |
| `"pasteImage.prefix"` | Markdown 里插入图片的前缀，确保能正确引用 | `"../"` |

---

### 示例：Markdown 图片插入
在 VS Code 里按 `Ctrl + Alt + V`（macOS 为 `Cmd + Alt + V`）粘贴截图后，插件会自动：
- 将截图保存为 `public/posts/index_20250130.png`
- 在 Markdown 里插入：
  ```md
  ![截图](../posts/index_20250130.png)
  ```

---

## 使用方法

### 1. 直接粘贴截图

- 在 Markdown 文件中按 `Ctrl + Alt + V`
- Paste Image 会把图片保存到 `public/photo/`，并在 Markdown 中插入：
  
  ```markdown
  ![描述](../photo/blog_20240130_153500.png)
  ```

### 2. 手动上传本地图片

- 也可以把本地图片拖到 Markdown 中，再运行 `Paste Image: Upload Image` 命令，让插件处理图片存放。

---

### 使用技巧
- **修改快捷键**：在 `Keyboard Shortcuts` 里搜索 `Paste Image`，设置粘贴快捷键。
- **更改图片位置**：调整 `pasteImage.path`，适配不同项目结构，例如存入 `public/posts`。
- **压缩图片**：可以配合 tinypng 之类的工具减小图片体积，改善加载速度。

---

## 结语

Paste Image 能省掉保存截图和填写图片路径的重复操作。经常在 Markdown 里贴图的话，可以装上试试。
