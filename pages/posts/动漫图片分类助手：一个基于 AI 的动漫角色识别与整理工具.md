## 前言

整理动漫图片时，常见的麻烦有：

- 图片越积越多，很难整理
- 不记得图片里的角色叫什么
- 想按作品分类，却忘了出处
- 手动分类太费时间
- 想找某个角色的图片要翻很久

这个工具主要有以下功能：

- 自动识别图片中的动漫角色和作品
- 按识别结果分类和整理图片
- 保存整理记录，方便下次使用
- 批量处理图片
- 支持多种识别模型

它适合这些使用场景：
- 同人画师整理素材
- 漫画爱好者分类收藏
- Galgame 玩家整理 CG
- 其他需要整理图片收藏的场景

## 功能特点

### 多模型支持
- 低精度动画模型（适用于动画原画）
- 高精度动画模型①（适用于同人、原画等）
- 高精度动画模型②（适用于各种场景）
- 高精度 Gal 模型①

### 分类模式
- 按角色分类：根据角色名称放入不同文件夹
- 按作品分类：根据作品名称放入不同文件夹
- 两种分类模式可以同时使用

### 识别模式
- 自动识别：批量处理图片，直接使用 API 返回的识别结果
- 手动确认：逐张确认识别结果，也可以手动修改

### 智能记忆
- 保存用户输入的角色和作品名称
- 从历史记录中快速选择
- 输入时提供自动完成

### 便捷操作
- 支持拖放文件夹
- 可以跳过不需要处理的图片
- 可以重新识别
- 结果会打包为 ZIP 文件

## 技术栈

- 前端框架：PyQt6
- 编程语言：Python 3.10+
- 打包工具：PyInstaller
- API 来源：[AnimeTrace](https://www.animetrace.com/)
- 其他依赖：
  - requests: HTTP 请求库
  - pathlib: 路径处理
  - json: JSON 数据处理
  - shutil: 文件操作

## 使用说明

### 基本操作
1. 启动程序
2. 点击"选择图片文件夹"按钮选择要处理的图片文件夹
3. 选择识别模型（建议先使用默认模型）
4. 选择分类模式（角色/作品/两者都选）
5. 选择是否自动分类
6. 点击"开始分类"按钮

### 手动确认模式
1. 查看识别结果
2. 可以：
   - 直接确认识别结果
   - 从历史记录中选择
   - 手动输入新的名称
   - 选择 `unknown`（未知）
   - 点击“跳过”跳过当前图片
3. 如果识别结果不理想，可以：
   - 切换其他识别模型
   - 点击“重新识别”

### 自动分类模式
1. 程序自动处理所有图片
2. 使用 API 返回的第一个匹配结果
3. 完成后自动保存并打包

### 结果保存
程序会创建以下目录结构：
  ```
  输出目录/
  ├── by_character/    # 按角色分类的结果
  │   ├── 角色1/
  │   ├── 角色2/
  │   └── unknown/     # 未识别的图片
  └── by_work/         # 按作品分类的结果
      ├── 作品1/
      ├── 作品2/
      └── unknown/     # 未识别的图片
  ```
- 最后打包为 ZIP 文件，可选择保存位置

## 注意事项

1. 图片要求：
   - 支持的格式：JPG、JPEG、PNG
   - 大小限制：单张图片不超过 4MB
   - 建议分辨率：不小于 256x256

2. API 限制：
   - 服务器繁忙时可能需要重试
   - 可能存在使用次数限制
   - 可能存在维护时段

3. 其他说明：
   - 历史记录保存在程序目录下的 data 文件夹中
   - 程序会自动清理临时文件
   - 建议处理同类型的图片时使用相同的识别模型

## 常见问题

1. **图片无法识别？**
   - 尝试切换其他识别模型
   - 检查图片是否清晰可见
   - 确认图片大小在限制范围内

2. **识别结果不准确？**
   - 尝试使用更高精度的模型
   - 使用手动确认模式进行修正
   - 可以输入正确的名称并保存

3. **程序无响应？**
   - 可能是服务器繁忙，稍后重试
   - 检查网络连接是否正常
   - 重启程序再次尝试
